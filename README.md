# tuneipv6

Tune encode/decode helpers for ipv6 payloads in pipelines.

**Site:** https://theworker02.github.io/tuneipv6/

## Install / run

```bash
git clone https://github.com/theworker02/tuneipv6.git
cd tuneipv6
node src/cli.js
node --test
```
